# _reference

Read-only reference material from sibling projects. Files here are kept temporarily during development to consult patterns, components, and conventions; they are not part of the deployed Redux app and should not be imported by anything in `src/`.

Current contents:

- `ParticleQuoVadis.js` – the source of the first app, *Particle, Quo Vadis?* (1D infinite square well). Useful while building Redux because the histogram component, slider with eigenstate snap, data export logic, and adaptive notes structure are all things Redux will re-implement in a finite-well variant.

Once Redux ships its analogous components and the reference is no longer being consulted, this folder can be deleted.
